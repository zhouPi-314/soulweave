## 审计中发现的真实事故（已修）

打包时做文件清点，发现 `app.asar` 里混进了**本地开发文件**：

```
\.env.local           ← 含 SOULWEAVE_DATABASE_URL（带口令）
\.npmrc
\.tmp\dsh-acl-locks\
\.dsh-runtime\profiles\
```

这是 D59.07（未授权/敏感内容不得发行）与 D56.24（打包隐私）的**实际违反**，不是理论风险。

**已修**：`electron-builder.yml` 增加 `!.env*`、`!.npmrc`、`!.tmp/**`、`!.dsh-runtime/**`、`!**/*.log`。
**已验**：重新 `pack:dir` 后 asar 条目 3050 个，泄露条目 0（仅剩一个 node_modules 里名字含 tmp 的正常文件）。

**遗留动作（需要你确认）**：仓库里现存的 `release/SoulWeave-Setup-0.1.0-s1.exe`（254.9 MB）是在修复**之前**构建的，
很可能仍含 `.env.local`。**不要分发那个文件**，请用当前配置重新打包后再发。
