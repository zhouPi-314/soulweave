## 判定规则（写死在脚本里）

- **阻塞**：`AGPL` / `SSPL` 系；`UNKNOWN` / `UNLICENSED`。
- **警告**：`LGPL` / `MPL` / `EPL` / `CDDL`（可分发，但要在 NOTICE 保留条款）。
- **通过**：MIT / ISC / Apache-2.0 / BSD / 0BSD / CC0 / BlueOak 等。
- 双许可表达式（如 `MIT OR CC0-1.0`）按"任一分支可接受"处理——选择宽松分支即可。
