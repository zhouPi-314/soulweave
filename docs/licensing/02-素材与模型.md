## 各阻塞项的具体要求

### SD 1.5（OpenRAIL-M）

- 再分发必须**附许可副本**与 Use Restrictions 摘要；
- 不得删除许可声明；
- 下载页与「关于」需要给出版本与许可链接（当前下载页已写"模型按需下载"，但**尚未附条款链接**）。

### Live2D Cubism SDK

- 保留 `Copyright(c) Live2D Inc.` 声明（已保留）；
- 不得单独再分发 SDK 本体；
- 有**年收入门槛**条款，超过需商业许可；
- 具体条款版本需在发行前复核（Live2D 会更新协议）。

### Hiyori 示例模型

- 仅限配合 Cubism SDK 使用；
- 不得单独售卖或再分发素材；
- 需保留官方署名。

### NapCat（新增阻塞，需你决定）

用户要求"默认 NapCat 内置并随包分发"。这与项目自己的 ADR-5 记录（"NapCat 许可禁止商用，不可打包"）冲突。

- 若 NapCat 许可确实禁止再分发：随包 = 侵权，必须改为引导安装；
- 若其许可在最新版本已放宽：需要**书面依据**（许可原文 + 版本号），写进 approvals.json 才能放行；
- 可选替代：换一个许可明确的 OneBot 11 实现，或自己实现最小协议端。

**当前状态：阻塞，未随包分发。**

### 语音音色

应用有 TTS 能力，但**音色来源没有记录**。这是 D59.03 里唯一完全未知的项：

- 如果用系统 TTS（Windows SAPI）：音色属于系统，随系统授权，可分发（我们不分发）。
- 如果用了第三方 TTS 模型/音色库：需要逐个确认许可，很多音色**禁止商用**。
- 如果录了真人声音：需要书面授权。
