About

关于 SoulWeave

SoulWeave 是「奇点跃迁」（Singulift）的数字生命项目：把长期记忆、语音与社交能力放进一个住在桌面的角色里。

它是什么

一个 Windows 多角色数字生命体验。用户可以创建并命名角色，为每个角色配置形象、人格、记忆与推理方式；角色之间共享产品能力，但记忆按角色隔离。

它不是什么

不是聊天套壳，不是云端服务，也不托管你的数据。没有账号体系，没有中心服务器。

源码状态

项目计划以 Apache-2.0 开源，但公开仓库当前尚未上线。官网不再把无效项目地址描述为可用源码入口。

公开前仍需完成隐私、许可与发布门禁；当前可关注 Singulift 的 GitHub 账号。

路线图

  • 开发记录显示已完成：多角色、Live2D、语音、长期记忆、QQ、权限审计、安装向导、自动更新。
  • 进行中：官网与文档、许可审计、发布流程。
  • 计划中：多语言界面、更多云端模型、记忆导出格式。
