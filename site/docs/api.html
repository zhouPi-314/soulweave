云端模型与 Key

本地角色使用本地模型；云端角色需要选择一个云端模型服务商。Key 由你自己申请，只存在本机。

配置

  1. 「智能体绑定」→ 选择要使用云端服务的角色
  2. 填供应商、Base URL、模型名、API Key
  3. 点「测试」确认可用，再保存

Key 的存放

Key 用系统安全存储加密，写在用户数据目录，不上传、不进日志。导出诊断信息时会自动脱敏。

额度与费用

「看板」会显示本月累计花费（按供应商返回的用量估算）。超额保护可在设置里设上限。

失败了会怎样

  • 网络错误：提示重试，不会静默失败
  • Key 无效：提示检查 Key，不消耗额度
  • 供应商限流：退避后重试一次，仍失败则明确报错
