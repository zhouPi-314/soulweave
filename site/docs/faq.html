FAQ

必须联网吗？

不是。本地角色可以选择本地模型与本地语音；云端角色、QQ 和下载资源包需要网络。

我的数据存在哪？

用户数据目录（默认在 %APPDATA%\SoulWeave）。记忆数据库在其中的 pgdata，配置是几个 JSON 文件。

卸载会删掉记忆吗？

默认不会。卸载时会问一次，选「否」就保留，重装后还能接着用。

能同时开两个吗？

不建议。同一个数据目录同时被两个实例写入会冲突；需要多开请用不同的数据目录。

支持 macOS / Linux 吗？

当前只发布 Windows 版。代码结构不排斥其他平台，但没有验证过的构建。

为什么安装包没签名？

代码签名证书成本较高，现阶段用 SHA-256 校验替代。SmartScreen 提示属于预期行为。

会收集我的聊天吗？

不会。没有中心服务器；官网上也没有统计脚本。
