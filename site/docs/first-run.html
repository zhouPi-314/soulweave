首次启动

第一次打开会进入四步向导，走完才会显示主窗口。

① 环境检查

检查系统版本、目录可写、数据库组件是否内置。有失败项会直接指出是哪一项。

② 数据库

  • 内置（推荐）：自动初始化到本机 55432 端口，数据在用户目录的 pgdata。
  • 已有数据库：填主机、端口、库名、用户、密码，点「测试连接」通过后继续。密码用系统安全存储加密保存。
数据库是必须项：记忆、角色、消息都依赖它。没有数据库时应用会明确提示「记忆不可用」。

③ 资源包

本地出图模型（4.07 GB）与语音模型（142 MB）可以现在下，也可以稍后在「下载中心」下。支持断点续传与 SHA-256 校验。

④ 完成

点完成后主窗口出现，向导不再打扰你。

安装到一半中断了？

下次启动会识别未完成的安装，在「维护」里点修复即可，不必卸载重装。
