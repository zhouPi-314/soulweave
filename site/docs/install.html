安装

1. 确认系统

  • Windows 10 1809+ 或 Windows 11，64 位
  • 至少 8 GB 内存、1 GB 可用磁盘（含全部模型约 6 GB）

2. 下载并校验

Get-FileHash .\SoulWeave-Setup-x.y.z.exe -Algorithm SHA256

与 Release 说明里的哈希比对。不一致就重新下载。

3. 运行安装程序

安装器是 NSIS 单文件。若被 SmartScreen 拦截：点「更多信息」→「仍要运行」（应用未签名，属正常提示）。

4. 选择安装位置

默认装在当前用户目录，避免要求管理员权限。安装包已包含数据库与语音引擎，不需要另外装 PostgreSQL 或 Python。

不会改你已有的环境。应用不使用系统 PATH 里的 Node/Python，也不写系统级环境变量。

卸载

控制面板卸载即可。卸载时会询问是否同时删除记忆数据，默认保留。
