QQ 接入

应用不内置 QQ 账号，需要你自备一个协议端（运行在你自己的机器上），再把角色接进去。

准备

  • 一个可用的 QQ 协议端，已登录你要用的账号
  • 协议端的本地地址与访问令牌（如果它有）

接入步骤

  1. 打开「社交」面板，填入协议端地址。
  2. 点「测试连接」，成功后会显示账号与在线状态。
  3. 在「角色档案 → 绑定」里选择这个角色要接的账号。
  4. 设置白名单：只有名单里的 QQ 号能触发回应。

群聊规则

  • 触发：被 @、命中关键词，或你显式开启的主动参与。
  • 额度：每位角色的讨论额度独立计算，超额会被拒绝而不是排队。
  • 并发：同一任务串行提交，避免同一句话被回两次。
默认拒绝。没有授权的账号发消息不会被回应；授权可随时在「权限」里收回。

注意

QQ 接入依赖第三方协议端，账号风险由其承担。请遵守腾讯的服务条款，不要用于骚扰或自动化营销。
