排障

顺序很重要：先看「维护 → 一键诊断」，它能覆盖大部分问题，而且不会改任何东西。

启动失败 / 白屏

  1. 看「维护 → 环境诊断」的失败项
  2. 若是数据库：确认 55432 端口没被占用
  3. 若上次在更新：应用会自动回滚，并在维护页显示回滚报告
  4. 仍然失败：把日志（已脱敏）提到 Issues

提示「记忆不可用 / 数据库未配置」

说明数据库还没初始化或配置丢失。到「维护」点修复，或重新跑一次向导。数据在 pgdata 目录，别手动删。

语音没有声音

  • 确认语音组件已下载（「下载中心」）
  • 检查系统输出设备是否被其他程序独占
  • 合成失败会退回文字，不影响对话

QQ 不回应

  • 协议端是否在线
  • 发消息的号是否在白名单
  • 当天讨论额度是否用完

更新失败

安装前会备份配置；连续两次启动失败会自动回滚到上一版配置，并暂停自动更新。恢复后在「版本与更新」里重新检查。

怎么取日志

「维护 → 环境诊断」页面底部可以导出诊断包（已自动脱敏）。提交前自己再看一眼。
