Capabilities

重点不在功能数量，而在于人格、记忆、表达与互动能否形成连续体验。

記

长期记忆

重要对话、偏好与经历可以被整理、关联和长期保存。角色不必在每一次相遇时重新认识你。

格

独立人格

角色拥有自己的身份、表达方式与行为倾向，而不是同一套回复的两种外观。

动

自主交互

在明确授权与频率边界内主动交流，不只等待下一条指令。

声

Live2D 与语音

动态形象、表情、语音识别与语音合成共同构成更自然的存在感。

多

多角色互动

创建多个角色，分别交流，也能在明确授权范围内让角色共同参与对话。

桌

桌面陪伴与 Life Studio

让角色进入 Windows 日常使用环境，并探索生活、创作与动态表达。

Local First

本地优先，但不对“全离线”作模糊承诺

角色、记忆与推理方式不同，联网边界也不同。产品官网应清楚说明哪一种能力依赖设备，哪一种依赖云端服务。

LOCAL FIRST

本地角色

选择本地运行方式时，角色可在你的 Windows 设备上工作，记忆与角色数据优先保存在本机。

推理环境
本地 DSH
数据位置
用户设备上的 SoulWeave 数据目录
联网场景
下载资源包、QQ、公告或你主动触发的工具调用
NETWORK REQUIRED

云端角色

选择云端模型服务时，角色需要网络和对应的 API Key 或服务额度。角色名称与身份仍由你定义。

推理环境
云端模型服务
数据边界
对话内容可能发送给你选择的模型服务商
费用边界
由服务商的计费规则和你的额度决定
注意：云端能力不是离线能力。模型不可用、网络中断或额度耗尽时，站点与产品说明都不能假装功能仍在正常运行。
Open Build

开放构建，共同探索数字生命的边界

项目以 Apache-2.0 代码许可与模块化架构推进。多角色身份、长期记忆与 AI 能力通过清晰边界组合，便于持续扩展与维护。
