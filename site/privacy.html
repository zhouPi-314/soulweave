隐私说明

最后更新：2026-11

本站（官网）

  • 不加载任何第三方脚本、字体或统计 SDK。
  • 不使用 Cookie、浏览器持久化存储或第三方追踪。
  • 公告与版本数据是同域静态 JSON，请求日志由托管方（GitHub Pages）按其策略处理，我们不额外记录。
  • 没有表单、没有邮件订阅、没有广告。

桌面端

  • 记忆、聊天记录、角色配置、语音模型都存在你的电脑上（用户数据目录）。
  • 数据库密码用系统安全存储（Windows DPAPI）加密后落盘，不写明文。
  • 卸载时默认保留记忆数据，只有你明确选择才会删除。
  • API Key 只在本机保存，不经过我们的服务器（我们没有服务器）。

联网范围

场景会发生什么
使用本地 DSH 模型不联网（除你主动触发的工具调用）
配置云端模型对话内容发往你选择的模型服务商，按其隐私政策处理
接入 QQ消息经由你自备的协议端与腾讯服务器
下载资源包只请求镜像地址上的模型文件
检查更新只请求版本清单，不上传任何使用数据
读取公告只请求本站的静态 JSON，失败时用本地缓存

删除数据

「维护 → 备份与导出」可以导出配置；卸载时可选择是否删除记忆数据库。数据库文件位于用户数据目录的 pgdata 下，删除即彻底移除。

当前尚无公开安装包；公开发布后将由 GitHub Releases 分发，本站不存储任何用户数据、密钥或聊天内容。
